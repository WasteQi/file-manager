# File Manager (Node.js CLI)

## 📌 Описание

CLI файловый менеджер, разработанный на Node.js (от 18 LTS) с использованием встроенных модулей Node.js API и Streams.

Приложение позволяет выполнять основные операции с файловой системой, получать информацию об ОС, вычислять хэш файлов, а также сжимать и распаковывать файлы с использованием Brotli.
